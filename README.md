# SCL-90 综合心理自评

移动端优先的中文 SCL-90（症状自评量表）H5。奶油 / 鼠尾草绿配色，一题一页，结果含总分、十因子表、雷达图和分项说明。

线上地址：<https://zengpenghui420-glitch.github.io/scl-90/>

## 怎么用

1. 打开页面，点「开始测试」
2. 输入验证码（`SC` + 4 位）。链接 `?code=SCXXXX` 会自动填好，确认后才扣次
3. 按最近一星期的实际感受做完 90 题。可返回上一题；刷新后本次作答还在
4. 查看总分、十因子表、带均分数字的雷达图，以及每项的心理特征表现和改善建议
5. 「重新测试」再扣 1 次；「查看上次结果」和「继续测试」不扣次

本机预览：

```bash
python3 -m http.server 8765
```

然后打开 <http://127.0.0.1:8765/> 。直接双击 `index.html` 时，验证码接口可能因浏览器限制失败。

## 计分

采用国内广泛使用的 **1–5 分**（从无 / 很轻 / 中等 / 偏重 / 严重）。总分范围 **90–450**。

因子均分 = 该因子原始分 ÷ 题数。展示前保留两位小数，再套用同一套分界：

| 水平 | 均分 | 对应总分（总均分 = 总分 ÷ 90） |
| --- | --- | --- |
| 正常 | < 2.00 | ≤ 179 |
| 轻度 | 2.00–2.49 | 180–224 |
| 中度 | 2.50–2.99 | 225–269 |
| 重度 | ≥ 3.00 | ≥ 270 |

因此 **232 分 → 总均分 2.58 → 中度**，和常见结果页的分档一致。

另外三个汇总：

- 总均分（GSI）= 总分 ÷ 90
- 阳性项目 = 单项 ≥ 2 的题数
- 阳性均分 =（总分 − 阴性项目数）÷ 阳性项目数；没有阳性项目时显示「—」
